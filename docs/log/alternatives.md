# Better options

When a captured asset has an assessment, its inspector shows same-workflow variants derived from live rule findings. Carbon can propose combinations of a closed list of changes and a one-time low, mode and high USD cost delta. The route uses stateless native structured output and validates the full response with Zod. A failed or invalid response leaves the rules-engine variants available.

The evaluator applies the exact candidate effects to an immutable twin snapshot and reruns the rules engine and the plant exposure model. Net annual value is baseline annual loss minus candidate annual loss minus the cost mode divided by five. Compliance gaps count asset findings with a compliance kind or a catalogue clause reference. Clause chips identify references that disappear entirely for that asset. The top option is recommended only when both deltas improve. The twin changes only when the engineer clicks **Use this**.

Rule variants use explicit simulated labor-hour ranges and the existing assumed blended rate. Options with unknown implementation costs stay available for review. Moves between process areas require workflow verification before they can be priced or ranked. Radio-off options use a labor estimate only when wired capability is documented. The enclosure effect records a modeled safeguard. The existing washdown rule still requires independent documented ratings and material evidence. Variants retain the device kind and can express only changes supported by the shared effect contract. No contract changes requested.

## Verify

The running endpoint returned HTTP 200 and three validated proposals from Carbon for a fictional wired inspection camera. A separate browser run took a real text capture through the pipeline. The rules-only recommendation appeared while Carbon ran, three Carbon proposals arrived, and clicking **Use this** on the radio-off variant changed the simulated plant risk dial from 48 to 47.
