# Evaluation data sources

The image captures are existing third-party photographs from Wikimedia Commons. They predate this benchmark and were taken independently of Pyre Witness. The curator selected and labelled them using source evidence. The JPEGs retain their original framing and use Commons thumbnails or proportional resizing to meet the capture limits.

The harness sends the JPEG bytes only. The source page, filename, labels and notes stay out of image inputs. The dataset is available to the team in this repository. Prior team exposure to particular public or familiar images and inclusion in model pretraining are unknown.

The Wikimedia Commons API supplied the file page, credited artist, description and licence for each capture. The file page records the applicable public-domain declaration where a separate licence URL is unavailable. Resized copies retain the source licence.
